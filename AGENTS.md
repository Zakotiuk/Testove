# Інструкції для агента

## Стек і структура

- Використовуй Playwright Test і TypeScript. UI-тести SauceDemo працюють у проєкті `chromium`, API-тести Restful Booker — у проєкті `api`.
- Для UI використовуй демонстраційного користувача `standard_user`. Бери облікові дані з фікстур. Публічні значення для запуску є в `.env.example`.
- Для кожного тесту готуй власний стан. Залишай окремі тести для незалежних сценаріїв і позначай їх `@main` або `@edge`.

## Page Objects і перевірки UI

- Успадковуй Page Objects від `Component`. Оголошуй локатори як окремі публічні поля без `readonly`. Для локатора конкретного товару використовуй поле-функцію, що приймає назву товару.
- Використовуй XPath через `locator(...)` і стабільні атрибути `data-test`. Усередині картки товару використовуй відносний XPath. Уникай залежності від позиції елемента або довгого шляху по DOM.
- Позначай дії Page Objects декоратором `@step()`.
- Для натискання використовуй у тестах окремі методи Page Objects із назвою елемента, наприклад `clickRemoveButton()`, `clickAddToCartButton()` або `clickCartLink()`.
- Залишай асерти в тестах. Перевіряй видимість там, де сценарій обіцяє показ елемента користувачу. Звіряй назви, ціни та підсумки з очікуваними даними тесту.

## API

- Використовуй запитну фікстуру Playwright і наявний `BookingApi`. Перевіряй точні HTTP-статуси та дані, важливі для сценарію.
- Створюй унікальні тестові бронювання. Змінюй і видаляй лише записи, створені тестом. Підтверджуй видалення запитом `GET`, який має повернути `404`.
- У негативному сценарії перевіряй побічні ефекти, якщо вони важливі. Наприклад, після відхиленого `PUT` повторно прочитай бронювання й звір його з початковими даними.

## Перевірка змін

- Для змін у TypeScript запусти `npm run typecheck` і відповідний набір через `npm run test:ui` або `npm run test:api`. Для змін у спільній конфігурації запусти `npm test`.
- GitHub Actions має запускати обидва набори на push і завантажувати HTML-звіт як артефакт `playwright-report`. У ручних перевірках і звітах розрізняй локальний прогін і запуск на GitHub.
