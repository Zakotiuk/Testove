# AI Worklog
## Інструкції для агента

Підтримувати Playwright + TypeScript, готувати стан окремо для кожного тесту й перевіряти очікувані дані. Для UI використовувати Page Objects із XPath і `@step()`. Для API створювати власні бронювання та підтверджувати їх видалення через `GET` зі статусом `404`. Повні правила та команди перевірки зібрані в [AGENTS.md](AGENTS.md).

## Що довелося виправити після AI

1. **Занадто складні локатори.** Під час перегляду Page Objects я побачила, що AI ускладнював пошук навіть для елементів із власним `data-test`. Я попросила використовувати цей атрибут усюди, де його достатньо. Наприклад, кнопку Checkout тепер знаходимо за `data-test="checkout"`.
2. **Назви методів для кліків.** У тесті кошика був виклик `removeProduct()`. З назви було зрозуміло, що товар видаляється, але хотілося, щоб у тесті було видно конкретну дію в UI. Я попросила назвати метод `clickRemoveButton()`. Так само `addToCart()` замінили на `clickAddToCartButton()`.
3. **Тест каталогу пропускав приховану картку.** Під час перевірки в тимчасовій копії приховали одну картку, а тест усе одно пройшов. Він перевіряв текст, який залишався в DOM. Додали перевірку видимості кожної очікуваної картки й повторили експеримент. Цього разу тест упав на прихованій картці. 

Код перевірили через `npm run typecheck` і локальний прогін `npm test` у CI-режимі. Пройшли всі 13 тестів, HTML-звіт сформувався.
